# Laboratorio

Plugin di 3Dschool per le lezioni di tecnologia:

- **Progetti guidati**: scatola, casetta per uccelli, sgabello, tavolino, panca, cassetto, cassetta degli
  attrezzi, mensola e libreria, dalle misure; ogni pezzo è un componente con il suo nome, così la lista
  di taglio lo legge subito.
- **Giunzioni**: scasso, battuta, mezzo legno, incastro a dita e foro.
- **Profili dei bordi**: smusso, arrotondamento e cavetto.
- **Fogli di montaggio**: un PDF con la lista dei pezzi e una pagina per pezzo.

Ispirato a WoodSketch (https://github.com/FMastro/woodsketch, Apache-2.0), riscritto per il sistema
dei plugin di Sawhorse.
