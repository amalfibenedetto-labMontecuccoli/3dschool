# Laboratorio

Plugin di 3Dschool per le lezioni di tecnologia:

- **Progetti guidati**: scatola, casetta per uccelli, sgabello, tavolino e libreria, dalle misure;
  ogni pezzo è un componente con il suo nome, così la lista di taglio lo legge subito.
- **Giunzioni semplici**: scasso, battuta e foro.
- **Profili dei bordi**: smusso e arrotondamento.
- **Fogli di montaggio**: un PDF con la lista dei pezzi e una pagina per pezzo.

Ispirato a WoodSketch (https://github.com/FMastro/woodsketch, Apache-2.0), riscritto per il sistema
dei plugin di Sawhorse.
